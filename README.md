# CACalm

Offline ambient mixer & Pomodoro focus timer for the CA Family ecosystem.

- **Multi-channel mixer** — blend multiple ambient sounds with per-channel volume
- **Pomodoro timer** — 25/5/25/15 focus cycles with auto-transition
- **Manual sound import** — add any audio file from your disk
- **100% offline** — no internet required, no account, no telemetry
- **Cross-platform** — Windows, macOS, Linux (one binary)

## Install

```bash
npm add @cecepazhar/cacalm
```

Or download the release from GitHub.

## Build from source

```bash
# Prerequisites: Rust stable, Node.js 20+, pnpm
cargo build --release
```

## Design System

CACalm follows the CADS (CA Design System) monochrome standard with Pro theming support.
